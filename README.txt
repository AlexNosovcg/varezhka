AR-открытка «Варежка» — как запустить

Состав
  index.html   — страница: камера, распознавание варежки, анимация (и режим без камеры)
  mitten.png   — лицевая сторона варежки из макета (обрезана по линии реза, фольга — серебро)
  targets.mind — метка для распознавания, собрана из mitten.png

Шаги
1. mitten.png уже сделан из макета варежка.ai. Если печать отличается от макета — замените файл.
2. targets.mind уже собран. Если поменяете mitten.png — пересоберите метку из новой картинки:
   https://hiukim.github.io/mind-ar-js-doc/tools/compile
3. Выложите всю папку на хостинг с HTTPS (без HTTPS камера не включится).
4. Сделайте QR-код на адрес страницы. Для печати — SVG, уровень коррекции M или H.

Проверка
  Откройте страницу на телефоне, нажмите «Включить камеру», наведите на варежку.
  Для первой проверки можно открыть mitten.png на мониторе и навести на него.
  Отладка кадра без камеры: добавьте к адресу #t-8.5 (секунда ролика).

Библиотеки three.js и MindAR грузятся с unpkg.com и cdn.jsdelivr.net.
Если нужна полная автономность, скачайте три файла из importmap в начале index.html
и замените адреса на локальные.
